================================================================================
GUIA DE SOBREVIVÊNCIA: TRABALHANDO EM COMPUTADORES QUE APAGAM AO DESLIGAR
================================================================================

Muitas faculdades usam sistemas de proteção (como Deep Freeze) que limpam 
completamente o disco rígido (C:) do computador sempre que a máquina é desligada 
ou reiniciada. 

Para não perder seu código, seus dados coletados e seu progresso, siga uma das 
três estratégias abaixo:

--------------------------------------------------------------------------------
ESTRATÉGIA 1: Trabalhar Diretamente no Pendrive (Recomendada para PC local)
--------------------------------------------------------------------------------
Em vez de salvar seus arquivos na área de trabalho ou na pasta Documentos do 
computador da faculdade, faça o Pendrive ser a sua pasta de trabalho.

1. Espete o Pendrive na máquina.
2. Abra o terminal (cmd ou Git Bash) apontando para a letra do seu Pendrive 
   (ex: E:\ ou F:\).
3. Clone seu repositório Git direto no Pendrive:
   git clone https://github.com/seu-usuario/seu-repositorio.git
4. Configure o usuário local do Git dentro da pasta no Pendrive:
   git config --local user.name "Seu Nome"
   git config --local user.email "seu_email@email.com"
5. Salve os dados coletados (arquivos CSV do IBGE/SIAP) diretamente no Pendrive.

-> POR QUE FUNCIONA: Ao desligar o computador, o disco C: será apagado, mas tudo 
   o que estiver gravado no seu Pendrive (dados, códigos e histórico do Git) 
   estará 100% seguro. Na próxima aula, basta espetar o Pendrive e continuar.

--------------------------------------------------------------------------------
ESTRATÉGIA 2: Programar no GitHub Codespaces (100% na Nuvem)
--------------------------------------------------------------------------------
Se você não quiser carregar um Pendrive, faça todo o desenvolvimento na nuvem 
pelo navegador.

1. Entre no seu GitHub pelo navegador da faculdade.
2. Acesse o seu repositório e clique no botão verde "Code" -> aba "Codespaces" 
   -> "Create codespace on main".
3. O navegador abrirá o editor VS Code completo rodando na nuvem do GitHub.
4. Qualquer arquivo criado, código escrito ou commit feito fica salvo na 
   sua conta do GitHub instantaneamente.

-> POR QUE FUNCIONA: O computador do laboratório serve apenas como uma tela. Se a 
   máquina for desligada da tomada ou travar, você não perderá nenhuma linha de 
   código, pois o ambiente virtual de desenvolvimento está rodando nos servidores 
   seguros do GitHub.

--------------------------------------------------------------------------------
ESTRATÉGIA 3: Backup Imediato no Google Drive / OneDrive
--------------------------------------------------------------------------------
Se você optar por salvar os arquivos no computador do laboratório temporariamente:

1. Baixe os dados e escreva seu código em pastas temporárias do sistema.
2. ANTES de desligar a máquina ou terminar o horário do laboratório:
   - Dê "Git Commit" e "Git Push" para enviar o código atualizado ao GitHub.
   - Faça o upload manual de novos arquivos de dados (CSV) para o seu Google 
     Drive ou OneDrive pessoal.
3. Certifique-se de que o upload terminou antes de desligar o computador.
