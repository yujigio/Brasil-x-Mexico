================================================================================
FLUXO DE TRABALHO 100% NA NUVEM: CÁLCULO E AGRO-CLIMA BRASIL VS MÉXICO
================================================================================

Este guia unifica as ferramentas para realizar todas as etapas do projeto 
diretamente pelo navegador. Não é necessário pendrive ou máquina física própria.

--------------------------------------------------------------------------------
1. MAPEAMENTO DAS FERRAMENTAS ONLINE (ECOSSISTEMA 100% NUVEM)
--------------------------------------------------------------------------------

- Código e Terminal: GitHub Codespaces (VS Code completo no browser).
- Análises e Rascunhos: Google Colab (Para testar funções matemáticas de Cálculo).
- Banco de Dados (CSVs): Google Drive Institucional (Para guardar arquivos baixados).
- Publicação do App: Streamlit Community Cloud (Hospeda o dashboard gratuitamente).
- Escrita do Artigo: Overleaf (Editor LaTeX online) ou Google Docs.

--------------------------------------------------------------------------------
2. PASSO A PASSO DO FLUXO DE DESENVOLVIMENTO
--------------------------------------------------------------------------------

PASSO 1: O Ambiente Virtual de Trabalho
- Logue no GitHub e crie um repositório para o projeto.
- Clique em "Code" -> "Codespaces" -> "Create codespace".
- A partir daqui, você tem um terminal e um editor de código que salvam seu 
  trabalho automaticamente no GitHub. Nada é apagado se o computador desligar.

PASSO 2: Coleta e Armazenamento dos Dados
- Use a internet da faculdade para baixar os dados do IBGE SIDRA e SIAP México.
- Se os datasets forem pequenos (<100MB), faça o upload deles diretamente 
  no seu repositório do GitHub dentro do Codespaces (pasta "data/raw").
- Alternativa: Salve no Google Drive e puxe os links direto no código.

PASSO 3: Desenvolvimento da Matemática (Simpson, Euler e Otimização)
- Se preferir testar os cálculos de forma interativa antes de codar no dashboard,
  crie um notebook no Google Colab (colab.research.google.com).
- Quando o algoritmo do Simpson (integral) e do Euler (EDO) estiverem funcionando,
  copie as funções de cálculo para o arquivo correspondente dentro do Codespaces.

PASSO 4: Criar e Testar o Dashboard
- No Codespaces, crie o arquivo "app.py" do Streamlit.
- No terminal do Codespaces, digite:
  streamlit run app.py
- O Codespaces detectará que uma aplicação foi iniciada e mostrará uma notificação:
  "Your application running on port 8501 is available. [Open in Browser]".
- Clique no botão para testar e ver o dashboard rodando em tempo real.

PASSO 5: Deploy Final (Publicar para o Professor)
- Salve todas as alterações com Commit e Push para o GitHub.
- Acesse o site do Streamlit Community Cloud (share.streamlit.io).
- Logue com sua conta do GitHub e clique em "New app".
- Selecione seu repositório, a branch "main" e o arquivo "app.py".
- Clique em "Deploy". Pronto! O link do seu trabalho está publicado e funcional.
