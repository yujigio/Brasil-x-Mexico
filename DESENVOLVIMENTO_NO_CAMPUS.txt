================================================================================
GUIA DE DESENVOLVIMENTO 100% NO CAMPUS (INCLUSÃO DIGITAL E ACESSIBILIDADE)
================================================================================

Este guia descreve como realizar todo o projeto utilizando apenas a 
infraestrutura física da faculdade (laboratórios) e ferramentas gratuitas 
em nuvem que rodam direto no navegador do computador.

--------------------------------------------------------------------------------
1. PROGRAMAÇÃO EM NUVEM (RODA DIRETO NO NAVEGADOR - SEM INSTALAR NADA)
--------------------------------------------------------------------------------
Se os computadores do laboratório da faculdade bloquearem a instalação de 
softwares (Python, VS Code, Git), use estes caminhos gratuitos pelo browser:

A. Google Colab (Ideal para as etapas de Matemática e Cálculo)
   - Como usar: Acesse pelo site (colab.research.google.com) usando a conta Google.
   - Vantagens: Já vem com Python, Pandas, Numpy, Scipy e bibliotecas de gráficos 
     instaladas por padrão. Não consome memória ou processamento do PC local.
   - Aplicação: Perfeito para programar a Regra de Simpson (Integral), o Método 
     de Euler (EDO) e ajustar a curva de otimização (Derivadas). Salva os 
     códigos direto no Google Drive do aluno.

B. GitHub Codespaces (Ideal para criar o Dashboard Streamlit e usar o Git)
   - Como usar: Acesse pelo site do GitHub criado para o projeto.
   - Vantagens: Disponibiliza 60 horas mensais gratuitas de uma máquina virtual. 
     Abre um editor VS Code completo direto no navegador.
   - Aplicação: O aluno pode programar o app do Streamlit e testá-lo clicando em 
     "Preview" na nuvem. Permite dar commits e pushs sem configurar Git no PC 
     físico do laboratório.

--------------------------------------------------------------------------------
2. ARMAZENAMENTO SEGURO (EVITE PERDER ARQUIVOS NO FIM DO DIA)
--------------------------------------------------------------------------------
Computadores de laboratório da faculdade costumam reiniciar e apagar tudo o que 
foi salvo no disco local C:. Proteja seu trabalho:

- Google Drive ou OneDrive Institucional: Utilize a conta de e-mail da faculdade 
  para armazenar os arquivos CSV baixados nas fases de coleta.
- GitHub: Faça o upload (Commit/Push) das alterações no repositório remoto a cada 
  término de sessão nos laboratórios.

--------------------------------------------------------------------------------
3. DIVISÃO DO TEMPO NO CAMPUS (SPRINTS DE LABORATÓRIO)
--------------------------------------------------------------------------------
Divida as tarefas em blocos focados que caibam nos horários de permanência 
no campus (ex: janelas de aula, horários de monitoria ou lab livre):

- Sessão 1: Coleta rápida de dados (1h30 no campus)
  -> Baixar dados agrícolas (IBGE/SIAP) e climáticos usando a internet da faculdade.
  -> Salvar os arquivos CSV no seu Google Drive.
- Sessão 2 e 3: Tratamento de dados e Cálculo no Google Colab (3h no campus)
  -> Importar os arquivos salvos do Google Drive direto no Colab.
  -> Implementar e testar os algoritmos de Simpson, Euler e derivadas.
- Sessão 4: Montagem do Dashboard e Publicação (2h no campus)
  -> Abrir o GitHub Codespaces no navegador do laboratório.
  -> Programar o dashboard interativo em Streamlit e fazer o deploy na nuvem.

--------------------------------------------------------------------------------
4. GRUPOS DE ESTUDO E PROGRAMAÇÃO PAREADA NO CAMPUS
--------------------------------------------------------------------------------
- Resolução no Papel: Reúnam-se na biblioteca do campus para resolver as equações 
  de derivadas e integrais no papel primeiro, facilitando a lógica antes de codar.
- Programação em Par (Pair Programming): Alunos com notebooks próprios podem levar 
  para o campus e programar ao lado dos que não possuem, compartilhando ideias 
  e ajudando no laboratório.
